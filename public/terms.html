2. Platform Architecture and Technical Design

2.1 Privacy-by-Design Architecture

ShareSecure is architected to be untraceable and privacy-preserving by design:

  • The Platform collects NO user accounts, email addresses, phone numbers, or personal identifiers.
  • The Platform performs NO IP address logging, geolocation, browser fingerprinting, device tracking, or behavioral analytics.
  • The Platform sets NO tracking cookies, session cookies, or persistent cookies of any kind.
  • Every file link is a cryptographically randomized, unique 8-character short ID with no traceable connection to the uploader.
  • The resharing mechanism generates entirely new, independent database rows with no parent-child linkage, making it technically impossible to reconstruct a sharing chain.
  • All file data is AES-256-GCM encrypted at rest. The encryption key is known only to the Operator.
  • No referrer headers, no search engine indexing, no caching, and no iframe embedding are permitted.
IP Address Notice: Your IP address is inherently visible to the server and any network infrastructure between you and the server. ShareSecure does not explicitly log IP addresses in its application code, but the underlying OS, web server, or hosting provider may retain connection logs outside this application's control. If your threat model requires IP anonymity, access this service over Tor or a trusted VPN.

2.2 Ephemeral Storage

All uploaded files are subject to mandatory expiry between one (1) minute and twenty-four (24) hours. Upon expiry, files are permanently and irrecoverably deleted. The Operator maintains no backup, archive, or shadow copy of expired content.

2.3 File Type Restrictions

The Platform only accepts PDF (.pdf) and Microsoft Word (.docx) files. File types are validated server-side by inspecting magic bytes — the actual binary signature of the file content — not merely the claimed extension or MIME type. This validation is a security measure; it does not affect the zero-knowledge nature of the Platform.

2.4 Third-Party Infrastructure

The Platform relies on Cloudflare Pages (cloudflare.com) and optionally Turso / libSQL (turso.tech). The Operator does not own or control these providers. Their independent terms and privacy policies govern their data handling.
