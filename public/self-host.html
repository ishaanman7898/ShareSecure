ShareSecure Open the app

Run your own ShareSecure

A private instance with no daily upload limit and files stored only on your machine.

Desktop app

Runs in its own window and keeps running in the tray, so your links keep working. It updates itself.

Download

First launch: on Windows, select More info → Run anyway. On a Mac, open the app once, then go to System Settings → Privacy & Security and choose Open Anyway.

Or install from the command line

What the command does

    After it’s installed

    Settings

    Settings live in the .env file inside the install folder. Restart the server after changing them.

    SettingDefaultWhat it does
    PORT3000Port the server listens on.
    BASE_URLlocalhostAddress used in share links. Set it to your domain if you run it on a server.
    USE_LOCAL_TUNNELtrueCreates a temporary public link so other devices can open your shares. Turn off if you have your own domain.
    ENCRYPTION_KEYGeneratedEncrypts every file on disk. Changing it makes existing files unreadable.
    DATA_DIRApp-data folderWhere the database and encrypted files are stored. Defaults to your user app-data folder.

    Install manually instead

    Requires Node.js 20 or newer and Git.

    git clone https://github.com/ishaanman7898/ShareSecure.git
cd ShareSecure
npm install
npm start

    The first start creates .env with a fresh encryption key. Source code and issues are on GitHub.
