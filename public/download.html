Docker Compose Recommended

The easiest way to run ShareSecure on a server or VPS. Docker handles all dependencies and keeps your data in a persistent volume.

Prerequisites

Docker Engine ≥ 24 Install from docs.docker.com
Docker Compose v2 Included with Docker Desktop or install the plugin
Git (optional) For cloning the repo — or just download the zip

Three commands

Terminal 
# 1. clone the repo
git clone https://github.com/ishaanman7898/ShareSecure
cd ShareSecure

# 2. create .env with a random encryption key
echo "ENCRYPTION_KEY=$(openssl rand -hex 32)" > .env
echo "BASE_URL=http://localhost:3000" >> .env

# 3. start
docker compose up -d

ShareSecure will be available at http://localhost:3000. Data is persisted in a Docker volume named sharesecure_data.

Useful commands

Management 
docker compose stop         # stop
docker compose start        # start again
docker compose logs -f      # live logs
docker compose down         # remove container (data kept)
docker compose down -v      # ⚠ remove container AND all data
Automated Installer No Docker needed

A single command that checks for Node.js, installs it if missing, downloads ShareSecure, generates your encryption key, and starts the server.

Bash / Zsh 
curl -fsSL https://raw.githubusercontent.com/ishaanman7898/ShareSecure/main/public/install.sh | bash

Or download and inspect first (recommended):

Inspect then run 
curl -fsSL https://raw.githubusercontent.com/ishaanman7898/ShareSecure/main/public/install.sh -o install.sh
less install.sh          # inspect first
bash install.sh          # then run

The script installs Node.js via nvm, Homebrew, or your system package manager if it's missing.

PowerShell (run as Administrator) 
irm https://raw.githubusercontent.com/ishaanman7898/ShareSecure/main/public/install.ps1 | iex

Or download and inspect first:

Inspect then run 
Invoke-WebRequest https://raw.githubusercontent.com/ishaanman7898/ShareSecure/main/public/install.ps1 -OutFile install.ps1
notepad install.ps1   # inspect first
.\install.ps1         # then run

The script installs Node.js via winget or downloads the official MSI installer. A desktop shortcut is created after install.

What the installer does: checks for Node.js ≥ 18 (installs if missing) → downloads ShareSecure → runs npm install → generates a random AES-256 encryption key → creates .env → starts the server on port 3000.
Manual Setup

Full control — install and configure everything yourself. Ideal for production deployments.

Requirements

Node.js ≥ 18 nodejs.org — LTS recommended
npm ≥ 9 Bundled with Node.js
~50 MB disk space Plus storage for uploaded files
  • 1
    Clone or download
    Clone the repository, or download and unzip it.
Terminal 
git clone https://github.com/ishaanman7898/ShareSecure
cd ShareSecure
  • 2
    Install dependencies
Terminal 
npm install
  • 3
    Create your .env file
    Copy the example and fill in your values.
Terminal 
cp .env.example .env
npm run generate-key   # prints ENCRYPTION_KEY=...  paste into .env
  • 4
    Configure .env
    Open .env and set BASE_URL to your domain or server IP.
.env 
PORT=3000
BASE_URL=https://share.yourdomain.com
ENCRYPTION_KEY=<your-64-char-hex-key>
  • 5
    Start the server
Terminal 
npm start   # production
npm run dev  # development (auto-restart on file change)

Running in production (optional)

Use a process manager like PM2 to keep ShareSecure running as a background service:

PM2 
npm install -g pm2
pm2 start server/index.js --name sharesecure
pm2 save
pm2 startup   # run as system service on reboot
Data & File Storage

Everything ShareSecure needs lives in the data/ folder. Back this up to keep your files safe.

Directory layout 
data/
├── sharesecure.db     # SQLite database (users + file records)
└── uploads/           # encrypted + compressed file blobs
    ├── Abc123....bin
    └── ...
Encryption: when ENCRYPTION_KEY is set, every file is compressed with zlib then encrypted with AES-256-GCM before being written to disk. Filenames and MIME types in the database are also encrypted. If you ever change or lose your key, existing files will become unreadable.
