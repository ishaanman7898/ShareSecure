Connect an AI assistant

Let Claude Code, Codex or any MCP client share files for you. Ask it something like “share report.pdf for 2 days” and it hands you the link.

Copy your token now. It won’t be shown again. Anyone with it can share files as you, so treat it like a password.

Run this in a terminal. Then ask Claude Code to share a file by its path.

Add this to ~/.codex/config.toml, and set SHARESECURE_TOKEN to your token.

In Claude on the web or the desktop app, open Settings → Connectors → Add custom connector. Name it ShareSecure and paste this as the MCP server URL. Then ask Claude to share or send something, and it does it for you.

This URL has your token in it, and it goes through the free public tunnel (loca.lt), so the tunnel can see it. Anyone with it can share and send files as you. Keep it private, and use Replace token if it gets out.

Apps like Claude need a public https address. Turn on the public link (USE_LOCAL_TUNNEL) or set BASE_URL to your domain, then create the token again.

Make a ShareSecure GPT that shares and sends files and text from the chat. In ChatGPT, open GPTs → Create → Configure, then:

  1. Paste these as the GPT’s Instructions:
    You share files and text through ShareSecure, and you do it yourself. For text you wrote (a summary, notes, a table), call shareText with the full text. For files in the conversation, ones the user attached or ones you made, call shareFiles with them. When the user names who it’s for, pass their ShareSecure usernames in send_to; to send a link you already made, use sendShare. Never ask the user to download, save or attach anything. If they don’t say how long the link should last, use 24 hours. Give them the link from the response, say who it was sent to, and mention when it expires. Use listShares to show their links and deleteShare to remove one.

  3. Set Authentication to API Key, auth type Bearer, and paste your token.
  4. Set the privacy policy to , then save the GPT (keep it private, or share it with a link).

If your ChatGPT plan lets you add connectors in developer mode, you can add ShareSecure there instead, using the connector URL from the Claude app tab with no authentication.

Delete your account

This erases your account and every file you’ve shared from it, right away. Your links stop working. It can’t be undone.

ShareSecure account

Link your ShareSecure account to send files to ShareSecure usernames. Sending to a username uploads an encrypted copy to ShareSecure’s servers so they can receive it when this computer is off. Links you share yourself stay on this computer.

Your password isn’t kept here. No account? Create one.
